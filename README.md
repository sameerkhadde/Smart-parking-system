## 🧠 About The Project

Finding an empty parking slot can be time-consuming, especially in crowded areas.

Our **Smart Parking System** provides a simple automated solution using **Arduino UNO, IR sensors, servo motors, and an LCD display**.

The system continuously monitors parking slots and provides real-time information about slot availability while controlling the parking gates automatically.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔍 **Slot Detection** | IR sensors detect whether a slot is occupied |
| 📺 **LCD Display** | Shows parking availability/status |
| 🚧 **Automatic Gates** | Servo motors control entry and exit gates |
| ⚡ **Real-Time Monitoring** | Continuously updates parking status |
| 💰 **Low Cost** | Uses easily available components |
| 🧩 **Expandable** | Can be upgraded with IoT and mobile apps |
